# gitgot

**gitgot** is a minimalist mail service with built-in donation system via CloudTips.

## Features

- 🔐 **Register by username** — create an account in seconds
- 🔑 **Two keys**:
  - `got-XXXX-XXXX-XXXX-@cloud` — login key
  - `username.@dbin` — public key for receiving messages (share with friends)
- 📧 **Email** — send and receive messages
- 📎 **Attachments** — attach files to messages
- 💸 **Donations** — link your CloudTips wallet and receive donations
- 🖼 **Avatar** — automatically generated from username via picsum.photos
- 🗑 **Delete messages** — permanently remove messages from the system

## How it works

### Registration
1. Enter your desired username
2. Click `Create`
3. Save the keys you receive:
   - `got-XXXX-XXXX-XXXX-@cloud` — for login
   - `username.@dbin` — for receiving messages

### Login
1. Paste your login key `got-XXXX-XXXX-XXXX-@cloud`
2. Click `Login`

### Send a message
1. Click `Write`
2. Enter recipient (DBIN key or `@username`)
3. Write your message and attach a file (optional)
4. Click `Send`

### Donations
1. In `Settings`, link your CloudTips wallet
2. In messages from users with CloudTips linked, a `Donate to sender` button appears
3. Click it — CloudTips page opens with pre-filled amount

### Avatar
- Automatically generated from username via `picsum.photos`
- Can upload your own avatar in Settings

## Technologies

- **Storage** — Backendless (table `Store`)
- **File upload** — ImgBB
- **Avatars** — picsum.photos
- **Donations** — CloudTips
- **Cryptography** — `crypto.getRandomValues()` for key generation
