# gitgot

[![Open gitgot](https://raw.githubusercontent.com/bro732965-oss/cloud-dbin/main/35017eb8_ddc7_420a_bce5_60e7ad049521.jpg)](https://gitchemist.netlify.app)

**gitgot** is a minimalist mail service with built-in donation system via CloudTips.

---

## Features

- 🔐 Register by username
- 🔑 Two keys: `got-XXXX-XXXX-XXXX-@cloud` and `username.@dbin`
- 📧 Send and receive messages
- 📎 File attachments
- 💸 CloudTips donations
- 🖼 Avatar from picsum.photos
- 🗑 Delete messages

---

## Installation & Run

```bash
git clone https://github.com/yourusername/gitgot.git
cd gitgot
open index.html
